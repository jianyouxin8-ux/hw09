## 程式用途與執行方式

### 程式用途
本程式處理「桌遊體驗」（每人 120 元）與「電影欣賞」（每人 80 元）兩場活動的原始報名字串。先將字串移除半形空白、轉小寫並以逗號拆分為 `list`，接著運用 `tuple`、`list`、`set`、`dict` 完成資料整理與統計：
- `tuple`：保存固定活動名稱，透過索引或拆包讀取。
- `list`：保留清理後但未去重的名單，以及排序後的名單與 `[:2]` 通知預覽切片。
- `set`：去除單場重複名單，並以交集（`&`）、聯集（`|`）與雙向差集（`-`）比較兩場參加者。
- `dict`：查詢各活動單價，並存放人數、報名人次與各場應收金額。

## 個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

- **以 3 人計算的原因**：桌遊整理串列 `['amy', 'ben', 'amy', 'cora']` 共有 4 筆，其中 `'amy'` 是因為原本大小寫與空白差異而重複出現兩次。依規則同一人在同一場活動重複報名只算一位參加者並收費一次，因此桌遊去重後為 3 人，應收 `3 × 120 = 360.00` 元。
- **直接拆成 `list`**：
  - **保留了**：原本的報名先後順序與重複出現的次數。
  - **失去了**：元素唯一性，也無法直接進行交集、聯集與差集運算。
- **再轉成 `set`**：
  - **保留了**：單場不重複的參加者集合，以及集合比對運算的能力。
  - **失去了**：原本的填寫順序與重複報名的次數紀錄。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

測試三中，桌遊去重集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 與電影去重集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 元素完全相同（$A = B$），因此交集 $A \cap B$ 與聯集 $A \cup B$ 皆為這 3 人，兩個差集 $A - B$ 與 $B - A$ 皆為空集合（`[]`）。

- **總不重複人數**：看聯集大小 $|A \cup B| = 3$ 人。
- **報名人次**：兩場各自去重後的人數相加，3 人各報兩場故為 $|A| + |B| = 3 + 3 = 6$ 人次。
- **總應收**：兩場分開計費，桌遊 $3 \times 120 = 360$ 元、電影 $3 \times 80 = 240$ 元，合計 $360 + 240 = 600.00$ 元。
